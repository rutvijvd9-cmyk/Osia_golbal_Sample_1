# OSIA GLOBAL (HK) LTD. — Interactive Website

This is a self-contained responsive website created from the information in the supplied 12-page company PDF.

Files:
- index.html — website structure and content
- styles.css — responsive styling, animations and visual system
- script.js — scroll reveals, counters, tabs, mobile menu, cursor glow and tilt interaction
- assets/ — visual page assets extracted from the supplied PDF

Open `index.html` in a browser to preview it.

The website intentionally preserves the company information supplied in the source material rather than replacing it with new claims or invented company details.
